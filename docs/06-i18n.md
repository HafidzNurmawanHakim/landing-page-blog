# 6. Multi Language (i18n)

> Bagian dari dokumentasi [Destitour Booking Platform](./index.md).

## 6.1 Bahasa yang Didukung

| Kode | Bahasa            | Default? |
| ---- | ----------------- | -------- |
| `id` | Bahasa Indonesia  | ✅       |
| `ms` | Bahasa Melayu     |          |
| `en` | English           |          |
| `zh` | 中文 (Simplified) |          |

## 6.2 Struktur File

```
messages/
├── id.json
├── ms.json
├── en.json
└── zh.json
```

## 6.3 Routing

- Prefix locale di URL: `/id/paket/...`, `/en/packages/...`, dst.
- Root `/` redirect ke `NEXT_PUBLIC_DEFAULT_LOCALE` (`id`)
- Memakai `next-intl` + middleware untuk locale detection

```
/id            → homepage (Indonesia)
/en/packages   → katalog paket (English)
/ms/booking/BATAM-3D2N → halaman sukses booking (Melayu)
/zh/packages/[slug] → modal booking (中文)
/zh            → homepage (中文)
```

## 6.4 Kategori Konten yang Diterjemahkan

- UI statis: navbar, tombol, label form, footer
- Halaman katalog & detail paket
- Notifikasi WhatsApp & Email template (dikirim sesuai locale customer)
- Halaman sukses booking

> **Catatan (keputusan implementasi):** konten paket disimpan sebagai **JSON object per field** — `{ id, ms, en, zh }` — pada kolom yang butuh terjemahan: `name`, `description`, `image_alt`, `itinerary`, `includes`, `excludes`. Field lain (`duration`, `price`, `code`, `slug`) tetap tunggal.
>
> **Blog (dok 13-blog.md):** pola yang sama dipakai di `blog_posts` & `blog_categories` untuk `title`, `excerpt`, `content`, `featured_image_alt`, `seo_title`, `seo_description` (post) dan `name`, `description` (kategori). `slug` & `content_type` tetap tunggal (`content_type` berlaku untuk semua locale). Migrasi `0010_blog_localization` membungkus nilai legacy menjadi `{ "id": <nilai> }`. Admin editor memakai locale tabs; konten di-resolve di publik via `pickLocale`/`localizeBlogPost` (lib/db/repositories/blog.ts).
>
> - Fallback: locale yang diminta → `id` (default) → locale tersedia pertama.
> - Di MVP, locale di-resolve di **client** via `I18nProvider` (`useI18n().locale`) dengan `localizePackage()` di `lib/db/repositories/packages.ts`. URL prefix `/id/`, `/en/`, dst. (next-intl + middleware) belum diterapkan — masih roadmap. `generateMetadata` memakai `id` sementara.
> - API `/api/packages*` menerima query `?locale=` untuk mendapatkan konten ter-resolve.
