# 8. Roadmap

> Bagian dari dokumentasi [Destitour Booking Platform](./index.md).

## Phase 1 – MVP (2–3 minggu)

| #   | Item                          | Status                    |
| --- | ----------------------------- | ------------------------- |
| 1   | Setup Next.js + OpenNext + D1 | ✅                        |
| 2   | Schema + Migration            | ✅                        |
| 3   | Homepage + Katalog            | ✅                        |
| 4   | Form Booking + Notifikasi     | ✅                        |
| 5   | Admin Dashboard sederhana     | ✅                        |
| 6   | Multi bahasa dasar            | ✅ (lightweight provider) |

**Target keluar MVP:**

- Customer bisa booking end-to-end
- Admin menerima notif + kelola status
- Biaya operasional ≤ $15/bulan

## Phase 2 – Improvement

- [ ] Payment gateway (Midtrans / Xendit)
- [ ] Generate Invoice PDF
- [ ] Filter & search admin lebih advanced
- [ ] Analytics sederhana

**Tujuan Phase 2:**

- Booking bisa dibayar online → mengurangi no-show
- Admin lebih efisien dengan filter/search
- Insight: paket mana paling laku, jam berapa booking ramai

## Phase 3 – Scale

- [ ] Multi admin + role
- [ ] Customer account
- [ ] Review & rating
- [ ] SEO advanced

**Tujuan Phase 3:**

- Tim bisa punya beberapa admin dengan hak akses berbeda
- Customer punya history booking + akun
- Review membangun trust → naikkan konversi
- SEO untuk datang dari Google (organic traffic)
